visant à estimer le risque de défaut de paiement à partir du jeu de données credit_risk_dataset (32 416 observations, 12 variables). Comparaison de la régression logistique, de Random Forest et de XGBoost, ainsi que de stratégies de gestion du déséquilibre des classes : absence de correction, pondération des classes et SMOTE. Meilleur résultat dans les expérimentations : XGBoost sans correction — ROC-AUC : 0,947 ; F1-score : 0,835 ; rappel de la classe défaut : 0,749. La pondération des classes a permis d'obtenir un rappel de 0,798. Le pipeline entraîné est exposé via une API REST FastAPI, avec validation des entrées par Pydantic. Une interface Streamlit permet de réaliser des prédictions individuelles ou à partir d'un fichier CSV.
